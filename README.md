# 🎙️ VOICE DUB V5 — AI Video Dubbing & Audio Translation Platform

**VOICE DUB V5** — современное веб-приложение для автоматической транскрибации, перевода, нейросетевого дубляжа и экспорта готовых аудиодорожек для видеоредакторов (CapCut, Premiere Pro, DaVinci Resolve).

---

## 🌟 Основные возможности

### 📥 1. Гибкий импорт (Этап 1)
- **Видео / Аудио файлы:** Поддержка форматов MP4, WebM, MOV, AVI, MKV.
- **Импорт оригинального текста:** Загрузка готовых файлов `.json` или `.txt` с таймкодами.
- **Импорт переведенного текста:** Прямой импорт переведенных фраз для мгновенного перехода к озвучке на 4 этапе.

### ✍️ 2. Транскрибация речи (Этап 2)
- Автоматическое извлечение речи с точными таймкодами через модель **Gemini 3.1 Flash**.
- Удобная интерактивная таблица для ручной корректировки оригинального текста.

### 🌐 3. Перевод фраз (Этап 3)
- Пакетный перевод через Gemini API.
- Поддерживаемые языки: **Русский, Персидский, Испанский, Египетский арабский**.
- Редактирование переведенного текста перед озвучкой прямо в таблице.

### 🎙️ 4. Нейросетевая озвучка Edge TTS (Этап 4)
- **Нейронные голоса:** Выбор между Мужскими 👨 и Женскими 👩 естественными нейроголосами для каждого языка.
- **Индивидуальная озвучка фраз:** Возможность изменить голос или перегенерировать (`🔄`) каждую отдельную фразу.
- **Выбор языка прямо на 4 этапе:** Синхронизированный селектор языка для работы без необходимости заходить на этап перевода.
- **Автоматическое микширование:** Склейка единого файла `.wav` запускается автоматически по завершении синтеза.

### 📤 5. Центр экспорта (Этап 5)
- **Склеенная аудиодорожка (.wav):** Единый файл дубляжа для CapCut с автоматической защитой от наложений (Anti-Collision Algorithm).
- **Экспорт текстов:** Скачивание оригинала и перевода в форматах `.json` и `.txt`.
- **Отдельные аудиофрагменты:** Скачивание всех озвученных фраз отдельными `.mp3` файлами.
- **Умная валидация:** Информативные предупреждения при попытке скачивания неотрендеренных данных.

## 🚀 Запуск и Развертывание

### 1. Локальный запуск (Python)
Для локального запуска выполните:
```bash
python server.py
```
Откройте в браузере: `http://localhost:8080`

### 2. Деплой на Vercel (Бесплатный хостинг)
Проект полностью подготовлен для быстрого развертывания на **Vercel**:
- [package.json](package.json) включает зависимость `ms-edge-tts`.
- [vercel.json](vercel.json) настраивает бесплатную бессерверную облачную функцию `/api/tts.js`.

#### Развертывание через Vercel CLI:
```bash
npm install -g vercel
vercel
```

## 🛠️ Технологический стек
- **Frontend:** Pure HTML5, CSS3 Tokens & Glassmorphism, Modern Vanilla JavaScript (ES Modules).
- **Audio Processing:** Web Audio API, OfflineAudioContext.
- **AI Models:** Google Gemini 3.1 Flash API (транскрибация и перевод).
- **TTS Engine:** Microsoft Edge TTS (Cloud Serverless / WebSockets fallback).
